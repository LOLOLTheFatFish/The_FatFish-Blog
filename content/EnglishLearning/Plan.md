## ✅ 一、GitHub 同步流程（每次更新网站只需 4 步）

> **前提**：你已写好日思（如 `9.27.md`）并复制到 `quartz/content/` 文件夹

### 操作步骤（在 PowerShell 中依次输入）：

```powershell
cd quartz                     # 进入项目目录
git add .                     # 标记所有新/改文件（告诉 Git：“这些我要上传”）
git commit -m "新增9.27日思"  # 给这次改动写个说明（比如“加了一篇笔记”）
git push                      # 真正上传到 GitHub
```

✅ 等 1–2 分钟，访问你的网站（`https://LOLOLTheFatFish.github.io/The_FatFish-Blog`），新内容就出现了！

> 💡 首次使用需先设置 Git 身份（只需一次）：
> ```powershell
> git config --global user.name "YourName"
> git config --global user.email "your@email.com"
> ```

## ✅ 二、本地启动 Quartz 网站（用于预览）

在 `quartz` 文件夹中运行：

```powershell
npx quartz build --serve
```

→ 浏览器访问 `http://localhost:8080` 即可预览  
→ 按 `Ctrl + C` 可停止服务

> ⚠️ 如果报错 `CustomOgImages`，请确保 `quartz.config.ts` 中已注释掉：
> ```ts
> // Plugin.CustomOgImages(),
> ```
